# Job Salary Prediction Dashboard Using Excel

## Project Description
An interactive Excel dashboard designed for Job Salary Analysis and Visualization.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

## Key Features
- Job Role Analysis
- Salary Comparison
- Salary Trends
- Interactive Dashboard
- Data Visualization

## Objective
To analyze job salary data and present meaningful insights through an interactive dashboard.
